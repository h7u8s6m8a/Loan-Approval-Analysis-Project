# Loan-Approval-Analysis-Project
## End-to-End Data Analyst project using python, Excel, SQL, and Power BI

✅About Project :
  
  This project analyzes loan application data to understand why some loans are approved and others are rejected.
  I used Python, SQL, Excel, and Power BI to clean data, analyze it, and create a dashboard.
  The main aim is to convert raw data into meaningful insights.

 ✅Objective :

   To find important factors that affect loan approval, such as:

   1.Applicant income

   2.Credit history

   3.Loan Amount

   4.Loan term

   5.Dependents

   6.Property Area

✅Tools Used :

   1.Python (Jupyter Notebook)

   2.Pandas, NumPy

   3.SQL

   4.Excel

   5.Power BI

✅ Project Steps Involved :

   1.Loaded dataset into Python and SQL

   2.Cleaned data (filled missing values using mean, median, and mode)

   3.Applied label encoding for categorical columns

   4.Created new columns (feature engineering)

   5.Built Power BI dashboard

   6.Wrote insights and conclusion

✅Key Insights :

   1.Applicants with good credit history get more loan approvals

   2.Higher income increases approval chances

   3.Loan amount and term affect approval

   4.Employment and dependents also influence results

✅ Conclusion :
    
  Credit history is the most important factor for loan approval.
Income and loan amount also strongly affect decisions.
This project shows how data can help banks make better decisions.
